# Pi Desktop design direction

The generated recommendation is stored in `design-system/pi-gui/MASTER.md`.

Pi Desktop adapts that baseline into a **graphite instrument-panel** UI: compact, calm, high-contrast, and keyboard-first. Warm amber is used only for active state and agent activity; mint is reserved for success. Manrope carries the interface and JetBrains Mono carries paths, tools, and metrics.
